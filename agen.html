Untuk agen AI

Yang bisa dilakukan agen pribadi di situs demo ini, lewat Personal Agent Protocol (Poppy) draft 0.1.

DEMO — Semua yang dijelaskan di halaman ini adalah simulasi. Tidak ada akun pasien, tidak ada pembayaran sungguhan.

1. Temukan klinik ini

Baca dokumen discovery di /.well-known/poppy.json:

https://xien63.github.io/.well-known/poppy.json

Dokumen itu menyebutkan nama dan domain klinik, server sign-in (OAuth), serta rute yang tersedia: website dan satu API demo (OpenAPI).

2. Periksa server sign-in

Sebelum percaya pada dokumen discovery, agen memeriksa metadata OAuth di /.well-known/oauth-authorization-server pada issuer yang tercantum, lalu memastikan issuer cocok persis dan poppy_domains memuat domain klinik ini. Itu aturan dari spesifikasi draft 0.1 bagian 3.2.

3. Pilih rute

  • Website: jelajahi halaman ini sebagai pengunjung biasa, atau gabung ke sesi lewat web.browser_session_endpoint bila sudah sign-in.
  • API demo: deskripsi OpenAPI di openapi.json menjelaskan jadwal dokter, pembuatan janji temu demo, dan pembayaran demo. Perhatian: di situs demo ini API-nya baru berupa dokumen, belum ada server API yang benar-benar berjalan. Menjalankannya adalah latihan lanjutan nomor 1 di panduan.

4. Buat janji temu demo

Alurnya: pilih layanan dan dokter dari jadwal, buat janji temu dengan scope appointments, lalu terima kode demo seperti DEMO-XXXXXX. Di situs ini langkah itu disimulasikan lewat formulir di halaman utama.

5. Pembayaran demo

Draft 0.1 tidak mengatur pembayaran. Jalur pembayaran untuk agen diatur lewat ekstensi checkout UCP, yang masih berupa usulan komunitas dan bukan bagian spesifikasi resmi. Karena itu demo ini tidak mencantumkan ekstensi pembayaran di poppy.json. Menambahkannya adalah latihan lanjutan nomor 2 di panduan.

Yang nyata dan yang simulasi

  • Nyata: dokumen discovery poppy.json, metadata OAuth, deskripsi OpenAPI, dan halaman-halaman situs ini.
  • Simulasi: sign-in (tidak ada server OAuth sungguhan), sesi dan token (tidak diterbitkan), pembuatan janji (hanya di browser), pembayaran (tidak ada).
