Token endpoint demo

DEMO — Ini bukan token endpoint sungguhan. Tidak ada Session Token atau Account Token yang diterbitkan di sini.

Di klinik sungguhan, endpoint ini menerbitkan access token dan refresh token (spesifikasi 1.0 bagian 4.4 dan 4.7). Client assertion dibatasi exp maksimal 5 menit sesudah iat, dan server wajib menerima ES256 dan PS384 (bagian 4.1). Di demo ini, endpoint hanya tercantum di metadata OAuth agar agen bisa menemukannya; token sungguhan adalah latihan lanjutan.
