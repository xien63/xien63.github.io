Halaman sign-in demo

DEMO — Ini bukan server OAuth sungguhan. Tidak ada akun, tidak ada token yang diterbitkan, dan tidak ada data yang dikirim.

Di klinik sungguhan, halaman ini adalah tempat pasien sign-in dan menyetujui akses untuk agen pribadinya (Direct Sign-In, spesifikasi draft 0.1 bagian 4.5). Di demo ini, langkah sign-in hanya dijelaskan, tidak dijalankan.
