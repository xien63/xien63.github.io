Halaman device sign-in demo

DEMO — Ini bukan server OAuth sungguhan. Tidak ada kode perangkat yang diterbitkan dan tidak ada akun yang dihubungkan.

Di klinik sungguhan, halaman ini melayani Device Sign-In (spesifikasi draft 0.1 bagian 4.6): agen menampilkan tautan dan kode, pasien sign-in di perangkat lain. Di demo ini, langkah itu hanya dijelaskan, tidak dijalankan.
