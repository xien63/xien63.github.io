Token endpoint demo

DEMO — Ini bukan token endpoint sungguhan. Tidak ada Session Token atau Account Token yang diterbitkan di sini.

Di klinik sungguhan, endpoint ini menerbitkan Session Token dan Account Token (spesifikasi draft 0.1 bagian 4.2 dan 4.8). Di demo ini, endpoint hanya tercantum di metadata OAuth agar agen bisa menemukannya; token sungguhan adalah latihan lanjutan.
